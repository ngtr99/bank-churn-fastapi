Bank Customer Churn Prediction is a machine learning web application that predicts whether a bank customer is likely to leave the bank based on key demographic and account-related features. The dataset used to train the model was sourced from Kaggle, where data preprocessing, feature engineering, and model training were performed. After training, the model was integrated into a backend service and deployed on Fly.io, allowing users to interact with the model through a web interface and receive real-time churn predictions. This application demonstrates an end-to-end AI workflow, from data acquisition and model development to cloud deployment and user-facing inference.
